## 1. Purpose

This document reviews the current BlueSea Foods document repository and identifies which documents should be updated, complemented, converted, or deprioritized to improve the quality of answers generated by the BlueSea AI Assistant.

The review was triggered by poor answer examples where the assistant retrieved fragments from weak or indirect sources, such as organization charts, CSV records, or isolated PDF snippets, instead of using explanatory source documents.

---

## 2. Main Diagnosis

The document base is usable, but retrieval quality is being affected by four issues:

1. Some source files explain concepts well, but they are in PDF or HTML and are being chunked poorly.
2. Some files only mention terms such as HACCP, temperature, access, or login without explaining them.
3. Operational registers, CSV, JSON, and spreadsheets are being retrieved for conceptual questions.
4. The assistant needs explicit FAQ-style and glossary-style documents to answer common employee questions.

Conclusion: yes, selected documents should be updated, including several PDFs. However, not all documents need to be rewritten. The highest-impact action is to convert or complement critical PDFs with clean Markdown versions and add short explanatory sections to the documents most likely to answer user questions.

## 7. PDF Recommendation

PDFs can remain as final presentation files, but they should not be the only indexed source for the assistant. For every important PDF, create a Markdown companion with the same content or a retrieval-optimized version.

Recommended pattern:

```text
BSF-CORP-002_Corporate_Glossary.pdf
BSF-CORP-002_Corporate_Glossary.md
```

The PDF remains useful for human reading and formal export. The Markdown version becomes the preferred RAG source.

## 9. Implementation Plan

### Phase 1: Critical RAG fixes

- Create `BSF-OPS-005_Cold_Chain_and_Freezing_Procedure.md`.

- Add quick-answer sections to `BSF-QMS-004`, `BSF-IT-002`, and `BSF-OPS-004`.

### Phase 2: Source cleanup

- Convert key PDFs to Markdown companions.

- Remove `.gitkeep` files from indexing.

### Phase 3: Legal, labor, and compliance reinforcement

- Update HR FAQ and leave/benefits policy.
- Create compliance/legal documents if missing.
- Add legal escalation and authority-request guidance.

### Phase 4: Reindex and evaluate

- Reindex the repository.
- Run test questions.
- Review bad answers.
- Add missing FAQ entries or source sections.

---

## 10. Final Recommendation

Yes, the documents should be updated, including selected PDFs. The priority should not be visual formatting; it should be retrieval quality.

The best approach is:

1. Keep formal PDFs for final documentation.
2. Add Markdown companions for all high-value PDFs and HTML files.
3. Add quick-answer sections at the beginning of critical documents.
4. Keep CSV/XLSX/JSON as lookup data, not conceptual answer sources.
5. Reindex only after the document structure is corrected.
