## 1. Purpose

This matrix identifies the existing BlueSea Foods documents that should be reinforced to improve the quality of answers generated by the corporate assistant.

The objective is not only to add more documents, but to ensure that each source document includes clear explanations, definitions, frequent questions, keywords and cross-references that help the RAG system retrieve useful evidence.

---

## 2. General Diagnosis

The assistant currently retrieves fragments from documents where a term appears, even when the document does not explain the concept. This causes incomplete answers for questions such as:

- What is HACCP?
- Cuales son las normativas para congelado?
- Explicame las temperaturas.
- Como es el acceso y login?
- Que hago si tengo un problema laboral?
- Puedo compartir documentos internos?

To improve answer quality, the knowledge base should prioritize explanatory documents over raw registers, organization charts, catalog files or documents that only mention keywords.

## 6. Reindexing Checklist

After updating the documents:

- confirm that filenames, document codes and areas are correct;
- remove duplicate or outdated versions from the indexed folder;
- reindex all updated Markdown, PDF, HTML, DOCX and spreadsheet files;
- test conceptual questions before operational/data questions;
- verify that CSV, JSON and XLSX files are not prioritized for conceptual questions unless the question asks for a specific record.
